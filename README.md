# Gesture Smart Camera (Web)

Browser version of my Python + OpenCV + MediaPipe gesture camera. Runs fully in the browser (no server, no upload).

- 12 filters: Dog, Cat, Sunglasses, Hearts, Snow, Fire, Neon, Rainbow, Vintage, B&W, Cartoon, Background (blur / colour)
- Hand gestures: pinch, swipe, open palm, fist, peace, thumbs up, two-hand heart, two-hand zoom
- Screenshot (PNG) and video recording (WebM)
- Tech: HTML, CSS, JavaScript, MediaPipe Tasks Vision, Canvas API, MediaRecorder

Open `index.html` through a web server (or deploy on Vercel). The camera needs HTTPS or localhost.
Keys: N next, P previous, C clear, S screenshot, R record.
